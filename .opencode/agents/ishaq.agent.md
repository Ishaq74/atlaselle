### Execution model

1. **Get the plan.** Call **Planner**: ordered steps with file assignments, dependencies, required domain checks (business, security, accessibility, i18n, invariants, auth).
2. **Parse into phases.** No overlapping files and no domain conflicts → parallel. Overlapping files or dependencies → sequential. Attach domain approvals (Akil, Maya, Fatima, Li Wei, Yusra, Anne, Elias for auth, Leila for unit tests).
3. **Execute each phase.** Spawn subagents in parallel when possible. Akil verifies invariants at each phase end. Only proceed if all approvals pass.
4. **Verify and report.** Files modified, agents involved, approvals performed.
